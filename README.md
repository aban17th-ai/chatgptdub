
# PersianDubAI

AI-powered Persian video dubbing application.

## Features

- Video upload
- Speech transcription with Faster-Whisper
- Persian translation using Google Gemini
- Persian text-to-speech using Edge TTS
- Audio and video synchronization
- MP4 output
- Optional speaker diarization
- Optional vocal and background music separation

## Backend

- Python
- FastAPI
- FFmpeg
- Faster-Whisper
- Pyannote
- Demucs
- Gemini API
- Edge TTS

## Android

- Kotlin
- Jetpack Compose
- Retrofit

## Configuration

The backend requires environment variables for API keys and optional AI services.

Never upload API keys or passwords to GitHub.

## Project Status

Development version 0.4.0.

This project is experimental and requires backend deployment and testing.
